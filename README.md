# QGIS на Astra Linux SE 1.6 (Смоленск)

Сборка QGIS 3.16.16 LTR из исходников для Astra Linux Special Edition 1.6 (платформа Debian 9 stretch: Qt 5.11 / gcc 6.3 / Python 3.5 / GDAL 2.1.2) и массовое развёртывание готовых .deb из собственного apt-репозитория. Машин сборки и установки: x86-64.

## Состав

```
qgis-astra/
├── QGIS-на-Astra-SE16.md          Стратегия: исходные данные, варианты, потолок версий,
│                                  сборка (раздел 4А), оценка пересборки GDAL (4Б), журнал
├── QGIS-массовое-развертывание.md Методика: состав репозитория, .deb, reprepro, установка
│                                  на целевые машины, МКЦ-нюансы, источники самосборов (2.4)
├── qgis-3.16-build/               Исходники и сборка QGIS 3.16.16 (+QScintilla, spatialindex,
│                                  PyQt5-модули), README со всеми деталями и патчами
├── metasearch-deb/                Python-пакеты для ядровых плагинов (owslib, pyproj,
│                                  plotly, nbformat): самосборы -astra, скрипт сборки
└── qgis-local-repo/               Готовые пакеты: debs/ (8 пакетов) и repo/ (reprepro)
```

Связь с инфраструктурой ОС (не входит в эту папку): установка ОУ10 — [../OU10-20211126SE16.md](../OU10-20211126SE16.md).

## Быстрый старт

- **Поставить готовый QGIS** (на машину Astra SE 1.6 с доступом к локальному репозиторию): [QGIS-массовое-развертывание.md](QGIS-массовое-развертывание.md), раздел 5.
- **Собрать с нуля** (машина разработки с диском средств разработки Astra 1.6): [qgis-3.16-build/README.md](qgis-3.16-build/README.md), затем скрипты `build-core-debs.sh` / `build-python-debs.sh`.

## Публикация (git)

В git включаются: документация, скрипты, маленькие исходные тарболлы, `.dsc`/манифесты. Бинарные пакеты (*.deb) распространяются через GitHub Releases, а не через git (в `.gitignore`); не публикуются: дерево сборки `qgis-3.16-build/build/`, распакованные исходники, бинарный cmake, ISO-образы. Подробнее об исключениях — в `.gitignore`.
